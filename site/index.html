NFC Desk Agent

A Windows 11 tray app that runs local scripts when your iPhone taps an NFC tag. The iPhone sends a signed HTTP request over your home Wi-Fi.

View on GitHub Releases

How it works

The shortcut signs the tag name and a timestamp with a secret you pair once. The agent checks the request in a fixed order and, if it passes, runs the script mapped to that tag from its own library. The request never carries a command, path or arguments.

Features

  • Tray appOpen Dashboard, Pair Phone, Pair New Tag, Pause/Resume, Open Script Folder, View Log, Show Notifications, Start with Windows, Quit.
  • Pairing windowA 32-byte random secret as 64 hex characters plus a QR code, the LAN URLs, and Regenerate secret.
  • Learning modeThe next validly signed tap from an unknown tag asks you to pick a script and a label. It ends after 2 minutes or one tag.
  • Script types.ps1, .bat, .cmd, .exe, .lnk, .py. Hidden window, your user rights, 60 s timeout, output in the log (64 KB cap).
  • Starter scriptsstart-work-day, focus-mode, lock-pc, media-play-pause, end-of-day.
  • LAN onlyBinds to private IPv4 addresses and 127.0.0.1. Default port 8765. Firewall rule for the Private profile only.
  • Local dataConfig, DPAPI-encrypted secret, scripts and 14 days of logs under %AppData%\NFCDesk\.
  • Self-containedA single-file NFCDesk.exe. No .NET install needed on the target PC.

Quick start

Requires the .NET 8 SDK to build. The published exe needs no runtime.

dotnet build
dotnet test
dotnet publish src/NfcDesk.App -c Release -r win-x64 -o publish

Run publish\NFCDesk.exe, accept the firewall prompt, then pair:

  1. Tray menu, Pair Phone. Note the secret and the URL, such as http://192.168.1.50:8765/tap.
  2. In the iPhone shortcut #50 "NFC · Send Tap to PC", paste the secret and URL into the Secret and PC text actions. Set the Tag text, for example desk-focus-01.
  3. Shortcuts, Automation, +, NFC, Scan. Choose Run Immediately and select the shortcut.
  4. On the PC, tray menu, Pair New Tag (Learning Mode).
  5. Tap the tag. Pick a script and a label when the agent asks.

Full steps, adding scripts and testing without a phone are in the README.

Protocol

One endpoint: POST http://<pc-lan-ip>:8765/tap with this JSON body.

{ "tag": "desk-focus-01", "ts": 1763441000, "sig": "<hex sha256>" }
  • tag: matches ^[a-z0-9-]{1,64}$.
  • ts: Unix time in seconds, UTC.
  • sig: lowercase hex of SHA256( tag + "|" + ts + "|" + secret ). The secret is the 64-character hex string from the pairing window.

Check order

  1. Source is a LAN address.
  2. Body format is exact. Maximum 1 KB.
  3. |now - ts| <= 30 seconds.
  4. ts is greater than the last accepted ts for this tag.
  5. Signature matches (constant-time compare).
  6. Tag is registered, or learning mode is on.
  7. Agent is not paused.

Requests are also limited to 10 per second per IP.

Responses

StatusBody
200{"status":"ok"}
403{"status":"denied"}, with no detail. The reason is in the log.

Security summary

  • Signed requests with a secret you pair once; non-LAN sources are rejected.
  • Replay protection: 30 s window plus a per-tag increasing timestamp, saved across restarts.
  • A request only names a tag. Scripts run only from the library folder, with strict path rules.
  • The secret is stored with DPAPI for the current Windows user.
  • No TLS in v1: anyone on your LAN can see tag names and tap times, but not the secret.

Troubleshooting highlights

SymptomCheck
iPhone says "PC didn't respond"App running, same Wi-Fi, network profile is Private, firewall rule exists, IP in the shortcut is current (reserve it in your router).
403 with ClockSkewPC or phone clock is off by more than 30 s. Sync time.
403 with BadSignatureSecret mismatch. Re-copy it with no spaces.
403 with UnknownTagRegister the tag with Pair New Tag (Learning Mode).
403 with NonLanSourceVPN on the phone, or a guest network with client isolation.
Script did not runRead its output in the log. Check the path rules.
Port in useChange port in config.json and the shortcut URL, then restart.

The log is in %AppData%\NFCDesk\logs\ (tray: View Log).
